Trois façons d'en sortir

Mise à niveau sur place

Windows Server 2025 accepte la mise à niveau directe depuis 2016. Rapide pour un serveur simple, risqué pour un serveur chargé d'historique.

Réinstallation et migration

Un serveur neuf en Windows Server 2025, puis migration des rôles et des données. Plus propre, c'est souvent le bon choix pour les contrôleurs de domaine.

ESU en dernier recours

Pour l'application qui ne peut pas bouger à temps. Payant, limité aux correctifs de sécurité, à combiner avec un plan de sortie daté.

Questions fréquentes

Quand se termine le support de Windows Server 2016 ?

Le support étendu de Windows Server 2016 se termine le 12 janvier 2027. Après cette date, Microsoft ne publie plus de correctifs de sécurité, sauf pour les clients qui achètent des mises à jour de sécurité étendues (ESU).

Peut-on passer directement de Windows Server 2016 à Windows Server 2025 ?

Oui. Microsoft prend en charge la mise à niveau sur place de Windows Server 2016 vers Windows Server 2025, hors cluster. Certains rôles ne la supportent pas : une réinstallation propre avec migration des rôles reste souvent plus sûre.

Les ESU sont-elles une bonne solution ?

Elles achètent du temps, jusqu'à trois ans, mais sont payantes, nécessitent en général la Software Assurance et ne livrent que des correctifs de sécurité. Elles conviennent aux applications impossibles à migrer à temps, pas à tout un parc.

Que comprend le forfait à partir de 2 500 € HT ?

La migration de jusqu'à 5 serveurs Windows Server 2016 vers une version supportée : inventaire des rôles et applications, nouvelle installation ou mise à niveau selon le cas, bascule, tests avec vous et documentation. Au-delà de 5 serveurs, le prix est fixé sur devis.

Mes serveurs tournent sur VMware : faut-il tout traiter en même temps ?

C'est souvent l'occasion. Réinstaller un serveur en Windows Server 2025 directement sur la nouvelle plateforme évite de migrer deux fois. Le diagnostic gratuit indique si les deux chantiers gagnent à être couplés.
